# Vehicle License Plate Recognition (Drishti Drive)

ANPR, traffic analysis aur vehicle tracking project.

## Setup
1. `pip install -r requirements.txt`
2. `python3 menu/app.py` chalao
3. Browser mein http://127.0.0.1:8000 kholo

## Note
- Demo videos repo mein nahi hain. Apni videos `menu/ANPR/video_footage/` folder mein daalo.
- `yolov8n.pt` model alag se download karo.
- Razorpay keys `.env` file mein daalo (PAYMENT_SETUP.md dekho).
